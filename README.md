# SwapLens

DistributedSwapLens optimizes workload migration and resource allocation through real-time monitoring and auto-scaling with SwapLensEngine on the SwapLensPlatform.

With SwapLens, you get a lightweight tool that stays out of your way.

**What you get**

- DistributedSwapLens optimizes workload migration and
- resource allocation through real-time monitoring
- and auto-scaling with SwapLensEngine on

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/SwapLens.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure SwapLens, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
